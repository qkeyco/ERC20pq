# Quantum Hub - Landing Page

Retro terminal-themed landing page for ERC-21 PQ infrastructure.

## Features

- 🎨 Retro 90s terminal aesthetic (VT323 font, green on black)
- 🖥️ CRT monitor effect with scanlines
- 🔗 5 clickable buttons linking to quantum infrastructure
- 📱 Responsive design
- ⚡ Fast Vite build

## Quick Start

### Development
```bash
npm install
npm run dev
```

Opens on http://localhost:5173

### Build
```bash
npm run build
```

### Deploy to Vercel
```bash
# Install Vercel CLI if needed
npm i -g vercel

# Deploy
vercel
```

Or use Vercel dashboard:
1. Import project from Git
2. Framework Preset: Vite
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Deploy!
